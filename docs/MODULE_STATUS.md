\# Development Rules



Every module progresses through the following lifecycle:



Planned



↓



Design



↓



Development



↓



Testing



↓



Stable



↓



Frozen



No module may skip any stage.



\---



\# Completion Criteria



A module is considered complete only when:



\- Functional implementation completed

\- UI completed

\- Validation completed

\- Logging completed

\- Documentation updated

\- Tests passed

\- Git commit created

\- Git tag created

\- Repository pushed



Only then may the module become \*\*Stable\*\*.
